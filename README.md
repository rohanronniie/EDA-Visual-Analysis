# Exploratory Data Analysis – Netflix & Iris

This repository contains exploratory data analysis performed on Netflix Movies & TV Shows dataset and the Iris dataset to study distributions, categorical behavior, outliers, and correlations.

## Datasets
- Netflix Titles Dataset
- Iris Dataset

## Analysis Performed
- Histogram distributions of numerical features
- Count plots for categorical features
- Box plots for outlier detection
- Correlation heatmaps
- Feature importance identification
- Visual interpretation and insights

## Tableau Dashboards

In addition to Python-based exploratory data analysis, interactive dashboards were created using Tableau to visually summarize key insights from the datasets.

### Netflix Dashboard
The Netflix dashboard provides insights into:
- Distribution of Movies vs TV Shows
- Content growth over release years
- Top contributing countries
- Rating and genre distribution

### Iris Dashboard
The Iris dashboard visualizes:
- Species distribution
- Relationship between petal length and petal width
- Feature comparison across species
- Clear separability of Iris-setosa

The dashboard files and images are available in the `tableau/` folder.
