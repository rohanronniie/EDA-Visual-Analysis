# Exploratory Data Analysis – Netflix & Iris

This repository contains exploratory data analysis performed on Netflix Movies & TV Shows dataset and the Iris dataset to study distributions, categorical behavior, outliers, and correlations.

## Datasets
- Netflix Titles Dataset
- Iris Dataset

## Analysis Performed
- Histogram distributions of numerical features
- Count plots for categorical features
- Box plots for outlier detection
- Correlation heatmaps
- Feature importance identification
- Visual interpretation and insights

## Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab
